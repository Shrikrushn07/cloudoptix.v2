# CloudOptiX 🚀

[![Live Demo](https://img.shields.io/badge/🚀_Live_Demo-cloudoptix--nu.vercel.app-blue?style=for-the-badge)](https://cloudoptix-nu.vercel.app/)

### AI-Driven Autonomous Multi-Cloud Resource & Workload Orchestrator

CloudOptiX is an enterprise-grade, autonomous multi-cloud management platform designed to optimize, self-heal, and orchestrate workloads seamlessly across **Amazon Web Services (AWS)**, **Microsoft Azure**, and **Google Cloud Platform (GCP)**. Leveraging advanced AI decision engines, it reduces cloud expenditure, minimizes operational latency, and enforces automated sovereign policy guardrails.

---

## 🌟 Key Features

* **Autonomous 8-Step Closed Loop:** Real-time infrastructure telemetry ingestion, anomaly detection, AI-driven root cause analysis, and zero-downtime automated remediation.
* **Multi-Cloud Arbitrage & Workload Migration:** Dynamic cost and performance optimization by shifting workloads across AWS (EKS/EC2), Azure (AKS/VMs), and GCP (GKE) based on live spot pricing and SLA demands.
* **Role-Based Access Control (RBAC):** Granular team personas including **SRE Admin** (full platform authority & chaos engineering), **FinOps Lead** (cost intelligence & budget constraints), and **Platform Engineer** (workload orchestration).
* **Interactive Chaos & Traffic Simulator:** Live simulation tools to inject spikes, trigger region failures, and observe autonomous multi-cloud self-healing in real-time.
* **Modern SaaS Landing & Control Center:** High-performance public marketing SaaS landing page coupled with a secure, real-time authenticated control plane.

---

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Vite, Tailwind CSS, Lucide Icons
* **State & Architecture:** Context API, Custom Autonomous Simulation Engine
* **Cloud Infrastructure Emulation:** Multi-Cloud Topology mapping for AWS, Azure, & GCP
* **AI Integration:** Google Gemini API for intelligent root-cause analysis and automated decision reasoning
